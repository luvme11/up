구동 방법

확인이 끝난 HTML은 아래 방법으로 실제로 구동할 수 있어요.

더블클릭으로 열기

다운로드한 .html 파일을 더블클릭하면 브라우저에서 바로 실행돼요.

로컬 서버로 열기

VS Code의 Live Server를 쓰거나 터미널에서 실행하세요.

python -m http.server 8000
# http://localhost:8000

GitHub Pages로 공개

  1. 저장소에 index.html 업로드
  2. Settings → Pages → Branch main / /(root)
  3. https://아이디.github.io/저장소/ 접속
